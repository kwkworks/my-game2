# 재의 왕관 - 텍스트 판타지 RPG

선택과 주사위(d20)로 이야기가 갈라지는 도트 그림 텍스트 RPG입니다.

- 직업 3개(전사·마법사·도적), 동료 3명, 턴제 전투
- 엔딩 9종 (좋은 2 · 중간 3 · 나쁜 4), 엔딩 도감
- 자동 저장/불러오기 (브라우저 localStorage)
- 도트 그림은 이미지 파일 없이 `script.js`의 코드로 그립니다

## 실행 방법

`index.html`을 브라우저로 열면 됩니다. (한 판 약 15분)

## 파일

- `index.html` 화면 뼈대
- `styles.css` 모양과 색
- `script.js` 이야기, 판정, 전투, 도트 그림
